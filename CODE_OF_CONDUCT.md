# Code of Conduct

AlterNet is a technical project about censorship-resistant publishing, local
identity, and user-controlled infrastructure. Collaboration here should be
direct, respectful, and careful.

## Expected Behavior

- be respectful and precise
- review code, not personalities
- explain risks with evidence
- welcome questions and learning
- keep discussions on topic
- handle security-sensitive information privately
- credit others' work

## Unacceptable Behavior

- harassment, threats, or personal attacks
- discriminatory language
- publishing private information without consent
- sharing exploit details publicly before a fix
- sustained disruption or bad-faith participation
- sexualized comments or unwelcome attention

## Security Discussions

If a comment includes practical exploit details, private keys, local databases,
unreleased vulnerabilities, or a working attack path, move it to the private
reporting process in [SECURITY.md](SECURITY.md).

## Enforcement

Maintainers may remove comments, close issues, request changes in behavior, or
restrict participation. Enforcement should be proportional and focused on
keeping the project safe and productive.

## Reporting

Report conduct concerns privately to the maintainers with relevant context,
links, and screenshots where possible.
